Amass

Amass puts +1/+1 counters on an Army you control, creating a 0/0 Army creature token first if you don't have one.

Keyword glossary › Amass

What it does

Amass is a keyword action, not an ability a creature keeps. Cards say “amass Zombies N” (or Orcs, in The Lord of the Rings sets). When that happens, you check whether you control an Army creature. If you don't, you create a 0/0 black Army token of that type. Then you put N +1/+1 counters on your Army.

Amass never makes a second Army while you have one. Each amass after the first adds counters to the Army you already have, so a deck full of amass cards turns one token into a large threat.

Older cards printed “amass N” without a type. Those now read “amass Zombies N” and work the same way.

Common mistakes

  • Making a second Army. If you already control an Army, the counters go on it instead.
  • Expecting the 0/0 token to die before the counters arrive. Both happen as the ability resolves, so it survives.
  • Attacking with a brand new Army. A token has summoning sickness like any other creature.
  • Treating a bonus like a counter. "Other Zombies you control get +1/+1" ends when that card leaves; amass counters stay.

Interactions worth knowing

  • If your Army leaves the battlefield, the next amass starts over with a fresh 0/0 token.
  • Proliferate grows the Army without amassing, by adding another counter of each kind it already has.
  • Cards that add extra +1/+1 counters, like Hardened Scales or Doubling Season, apply to every amass.
  • An Army that gets amass Zombies and amass Orcs becomes both: a Zombie Orc Army.
